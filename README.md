## ✨ المميزات

- 📋 إدارة المناديب والعهد المالية
- 🧾 تسجيل الفواتير مع مراكز التكلفة
- 📄 المصروفات بدون فواتير
- 💰 طلب عهد جديدة من المندوب
- 📊 تقارير مالية مفصلة
- 🏢 الموردين والشركات
- 🖨️ طباعة التقارير بتنسيقات احترافية
- 📥 تصدير CSV و Excel
- 📤 استيراد وتصدير JSON
- 🔒 تسجيل دخول بـ PIN للمناديب
- 📱 متوافق مع الجوال

## 🛠️ التقنيات

| المكون | التقنية |
|--------|---------|
| الخادم | Python + Flask |
| قاعدة البيانات | Google Sheets (عبر Apps Script) |
| الواجهة | HTML + CSS + JavaScript |
| النشر | Render.com |

## 📁 هيكل المشروع
